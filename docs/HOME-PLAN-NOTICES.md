# Notices du candidat autonome Home Plan

Le module `candidates/home-plan/home-plan-card.js` incorpore le runtime Lit résolu par `package-lock.json` sans modification :

- `lit-element@4.2.0`
- `lit-html@3.3.3`
- `@lit/reactive-element@2.1.2`

Le build incorpore aussi les directives standard SVG et de listes à clés. Aucun import CDN ni dépendance runtime à une autre carte. Le texte BSD-3-Clause ci-dessous est également incorporé dans le module autonome installé.
